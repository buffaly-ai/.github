# Contributing to Buffaly

Buffaly is developed by Matt Furnari. Contributions are welcome, but major external code contributions may require a Contributor License Agreement (CLA) before acceptance.

## Where to contribute

- **[Agent Kit](https://github.com/buffaly-ai/agentkit)** — the public reference implementation. This is the primary repository for external contributions: bug reports, documentation improvements, sample enhancements, and tool integrations.
- **[ProtoScript](https://github.com/buffaly-ai/protoscript)** — language, parser, interpreter, and workbench.
- **[Ontology](https://github.com/buffaly-ai/ontology)** — prototype graph runtime, parsers, and simulation.
- **[Skills](https://github.com/buffaly-ai/buffaly-skills)** — community and bundled skill packages.

Other Buffaly repositories are maintained privately. If you are interested in contributing to a component that is not publicly visible, open an issue in the Agent Kit repo and we can direct you.

## Before contributing

- Open an issue first for major changes.
- Keep examples free of PHI, secrets, credentials, customer data, private logs, and confidential information.
- Follow existing project patterns.
- Keep changes focused and reviewable.

## CLA expectation

Major code contributions are expected to require a CLA. Small documentation fixes, typo fixes, and issue reports may be handled without a CLA at the maintainer's discretion.

## Licensing

Buffaly core is GPLv3 by default. Commercial licensing is available for organizations that need different terms for proprietary use, redistribution, private embedding, hosted product use, or supported deployment.
